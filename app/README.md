## Ограничение платформы

Устройство разработки — iPhone, ноутбук на Windows. Значит:

* нативную iOS-сборку собрать нельзя (нужен Mac с Xcode);
* Expo Go работает, но нативные модули в нём недоступны,
  следовательно YOLO на самом телефоне не запустить.

Отсюда архитектура: **телефон = датчики и звук, ноутбук = вычисления**.

```
iPhone (раздаёт Wi-Fi) -----> ноутбук в рюкзаке (NVIDIA, весь compute)
  камера        --------->      core/ через server/
  GPS + компас  --------->
  наушник       <---------      синтезированная речь
```

Схема уже проверена в исходном проекте: в `mobile_expo/App.js`
зашит адрес `172.20.10.3` — это подсеть iPhone Personal Hotspot.

В статье это называется edge-assisted архитектурой и описывается
честно, вместе с планом переноса на устройство.

## Экраны (проектируем на шаге 4)

1. Ввод пункта назначения голосом
2. Активная навигация — крупный контрастный экран + VoiceOver
3. Экстренная остановка
4. Настройки: язык, темп речи, чувствительность

Главное требование: интерфейс должен полностью работать **без взгляда на экран**.
Основной канал — звук и вибрация; экран нужен зрячему сопровождающему
и для отладки.
