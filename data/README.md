# Данные

Содержимое каталога в git не хранится — только структура и описания.

```
osm/            выгрузка OpenStreetMap по Астане
                  astana_pedestrian.osm.pbf
                  snapshot.json      дата и bbox выгрузки (нужно для статьи)

models/         веса
                  yolov8m.pt         базовая детекция
                  yolov8m_kz.pt      дообученная (шаг 5)
                  midas_small.pt     оценка глубины
                  tts/               голоса Piper: kk_KZ, ru_RU

walks/          записанные прогулки — ГЛАВНЫЙ СОБСТВЕННЫЙ ДАТАСЕТ
                  <walk_id>/
                    video.mp4
                    track.jsonl      GPS + компас
                    meta.json        маршрут, погода, освещённость, время
                    hazards.jsonl    ручная разметка опасностей (ground truth)

object_profiles.csv    приоритеты классов, kk/ru/en названия, высоты
```

## Что нужно собрать

| # | Что | Объём | Когда |
|---|-----|-------|-------|
| 1 | Выгрузка OSM Астаны | один файл | шаг 3 |
| 2 | Прогулки по Астане | 15-20 маршрутов | шаг 6 |
| 3 | Разметка опасностей на них | по всем прогулкам | шаг 6 |
| 4 | object_profiles.csv с казахским | ~80 строк | шаг 4 |

Прогулки снимать в разных условиях: день/сумерки, ясно/снег, будни/выходные.
Условия фиксировать в meta.json — по ним строится разбивка результатов
в статье (как таблица по освещённости в работе Ж. Каржаубай).
