# Мокапы

Делаем на шаге 4, после того как зафиксируем контракты слоёв.

Порядок важен: сначала **сценарии озвучки**, потом экраны.
Для незрячего пользователя интерфейс — это последовательность
реплик, а не картинка. Экран вторичен.

## 1. Сценарии озвучки (главное)

Расписать посекундно, что слышит человек:

* обычный проход по тротуару
* обход препятствия без схода с маршрута
* перекрытый тротуар, перестроение маршрута
* подход к регулируемому переходу и переход
* подход к нерегулируемому переходу
* потеря GPS
* экстренная остановка
* прибытие
