# Сценарии озвучки

Главный документ проектирования интерфейса. Для незрячего пользователя
интерфейс — это **последовательность реплик во времени**, а не экран.
Всё остальное (экраны, кнопки, вибрация) вторично и выводится отсюда.

Каждый сценарий расписан посекундно. Столбец «слой» показывает, какой
модуль порождает реплику, — это спецификация для `core/guidance/phrasing.py`
и `core/guidance/scheduler.py`.

---

## Правила, общие для всех сценариев

**1. Сначала действие, потом причина.**

> «Возьмите левее — впереди яма»

а не «впереди яма, возьмите левее». Человек должен начать действовать
с первого слова, не дожидаясь конца фразы. При скорости 1.2 м/с фраза
длиной три секунды описывает участок, который уже пройден наполовину.

**2. Экстренное сообщение — одно слово.**

> «Стоп»

Всё остальное после остановки.

**3. Расстояния округляются до отмеряемых шагами величин:** 5, 10, 20, 40 м.
«Тридцать семь метров» человек всё равно не отмерит.

**4. Метры произносятся, только если им можно верить.**
При `distance_sigma_m` выше порога — «близко» / «впереди», без числа.
Ложная точность подрывает доверие ровно тогда, когда оно нужнее всего.

**5. Направление — в терминах тела** (левее, правее), не в градусах
и не в сторонах света.

**6. Бюджет речи: не чаще одной реплики в 2.5 секунды.**
Незрячий ориентируется на слух. Приложение, говорящее непрерывно,
отбирает у него основной канал восприятия.

**7. Утверждения о мире и утверждения о системе различаются.**
При низком `health.confidence`: не «свободно», а «препятствий не вижу».

## Сценарий 1. Обычное движение по тротуару

Базовая линия. Система молчит большую часть времени — это норма,
а не признак неисправности.

| Время | Реплика | Слой | Почему |
|---|---|---|---|
| 0:00 | «Маршрут построен. Восемьсот метров, примерно двенадцать минут. Идите прямо.» | routing | подтверждение старта |
| 0:12 | *(молчание)* | — | ничего не изменилось |
| 0:40 | «Через сорок метров поворот направо.» | routing | предупреждение о манёвре |
| 1:05 | «Через десять метров поворот направо.» | routing | второе предупреждение |
| 1:14 | «Поворот направо.» | routing | момент манёвра |
| 1:20 | *(молчание)* | — | |

**Проверяемое свойство:** между 0:12 и 0:40 система молчит 28 секунд.
Если в этом промежутке звучат реплики о распознанных объектах,
арбитраж работает неправильно.

## Сценарий 2. Обход препятствия без схода с маршрута

Ключевой сценарий работы. Показывает то, чего нет ни у маршрутных,
ни у распознающих приложений: **одна фраза выражает оба уровня**.

| Время | Реплика | Слой | Состояние |
|---|---|---|---|
| 0:00 | «Идите прямо сорок метров, потом направо.» | routing | θ_route = 0° |
| 0:06 | «Возьмите левее — впереди яма.» | **fusion** | θ* = −18°, отклонение допущено |
| 0:11 | «Возвращайтесь правее.» | **fusion** | препятствие пройдено |
| 0:14 | *(молчание)* | — | на маршруте |
| 0:35 | «Через десять метров поворот направо.» | routing | |

Что происходит внутри на 0:06:

```
routing:  θ_route = 0°   (прямо)
risk:     сектор −5°…+10° занят (яма, риск 0.9)
local:    свободные коридоры: −25° (ширина 22°), +30° (ширина 14°)
fusion:   cost(−18°) минимальна → BEAR_LEFT, причина = «яма»
```

**Отдельно важно 0:11.** Без возврата на маршрут человек уйдёт в сторону:
после трёх обходов он окажется на другой улице. Это то, что ломает
наивную схему «сначала маршрут, потом объезд».

## Сценарий 3. Перекрытый тротуар, перестроение маршрута

Отклонение бывает двух видов, и система обязана их различать.

| Время | Реплика | Слой | Состояние |
|---|---|---|---|
| 0:00 | «Идите прямо.» | routing | |
| 0:05 | «Возьмите правее — впереди преграда.» | fusion | подруливание? |
| 0:09 | «Возьмите правее.» | fusion | отклонение держится |
| 0:13 | «Тротуар перекрыт. Перестраиваю маршрут.» | fusion → routing | `replan_needed` |
| 0:16 | «Новый маршрут, на семьдесят метров длиннее. Поверните налево.» | routing | |

**Различение:** отклонение больше 25° держится дольше 4 секунд →
это не обход столба, а перекрытый путь. Порог задан
в `FusionConfig.sustained_deviation_s`.

Реплика на 0:13 обязательна: без неё человек не понимает, почему
маршрут изменился, и решает, что система сбоит.

## Сценарий 4. Регулируемый пешеходный переход

Самый опасный участок маршрута. Отдельный протокол из четырёх фаз.

| Время | Реплика | Фаза | Почему |
|---|---|---|---|
| 0:00 | «Через двадцать метров переход. Регулируемый, со звуковым сигналом.» | APPROACHING | заранее, чтобы успеть подготовиться |
| 0:12 | «Переход через пять метров.» | APPROACHING | |
| 0:16 | «Край тротуара. Стойте.» | WAITING | **бордюр — тактильный ориентир** |
| 0:17 | *(вибрация: два коротких)* | WAITING | дублирование в шуме улицы |
| 0:31 | «Сигнал. Можно идти. Прямо, двенадцать метров.» | WAITING → CROSSING | |
| 0:34 | «Держите прямо.» | CROSSING | удержание курса |
| 0:39 | «Возьмите чуть правее.» | CROSSING | коррекция сноса |
| 0:44 | «Переход пройден. Бордюр.» | COMPLETED | |

**Почему на проезжей части поведение другое:** в фазе `CROSSING`
вес маршрута повышается, широкие отклонения запрещены. Сойти с курса
между машин опаснее, чем задеть что-то на тротуаре.

**Реплика 0:16 — «край тротуара»** привязана не к GPS (точность 5–15 м
не годится), а к обнаружению бордюра камерой. Это пример того, где
локальный уровень уточняет глобальный.

## Сценарий 5. Нерегулируемый переход

Система **не принимает решение за человека**. Она не может оценить
поток машин достаточно надёжно, чтобы взять на себя ответственность.

| Время | Реплика | Фаза |
|---|---|---|
| 0:00 | «Через двадцать метров переход. Нерегулируемый — будьте осторожны.» | APPROACHING |
| 0:14 | «Край тротуара. Стойте. Здесь нет светофора.» | WAITING |
| 0:16 | «Слева машина, приближается.» | WAITING |
| 0:22 | «Машин не слышу и не вижу. Решение за вами.» | WAITING |
| — | *(ждём подтверждения пользователя: двойное касание или голос)* | WAITING |
| 0:30 | «Иду с вами. Прямо, десять метров.» | CROSSING |

**Формулировка 0:22 намеренная.** «Можно идти» система здесь сказать
не вправе: она не видит весь поток, и ошибка стоит жизни. «Не вижу»
описывает состояние системы, а не состояние дороги — и оставляет
решение за человеком.

Это прямое следствие правила о разграничении утверждений о мире
и утверждений о системе.

## Сценарий 6. Деградация: наступила темнота

Молчание системы неотличимо от «впереди чисто». Отказ обязан звучать.

| Время | Реплика | Слой |
|---|---|---|
| 0:00 | «Темнеет. Вижу хуже — будьте внимательнее.» | health |
| 0:04 | «Идите прямо.» | fusion |
| 0:20 | «Впереди препятствие. Точно не вижу — обойдите слева.» | fusion, low confidence |
| 0:50 | *(молчание — напоминание не чаще раза в 30 с)* | health |
| 0:60 | «Всё ещё темно. Препятствий не вижу, но полагайтесь на трость.» | health |

Обрати внимание на разницу формулировок при `confidence < 0.6`:

| Обычно | При низком доверии |
|---|---|
| «Свободно» | «Препятствий не вижу» |
| «Впереди яма в трёх метрах» | «Впереди что-то, близко» |
| «Можно идти» | «Решение за вами» |

## Сценарий 7. Потеря GPS

| Время | Реплика | Слой |
|---|---|---|
| 0:00 | «Положение потеряно. Веду по камере, направление могу путать.» | health |
| 0:05 | «Впереди свободно.» | fusion (только зрение) |
| 0:25 | «Положение восстановлено. Вы на маршруте, до поворота тридцать метров.» | routing |

При потере GPS система **не замолкает** — локальный уровень продолжает
работать. Но маршрутные реплики прекращаются: вести по азимуту,
не зная своего положения, значит уводить наугад.

## Сценарий 8. Экстренная остановка

| Время | Реплика | Приоритет |
|---|---|---|
| 0:00 | «Идите прямо, через сорок...» | NAVIGATION |
| 0:01 | **«СТОП.»** *(речь прерывается на полуслове)* | EMERGENCY |
| 0:02 | *(вибрация: длинная)* | EMERGENCY |
| 0:03 | «Машина прямо перед вами.» | EMERGENCY |
| 0:07 | «Проехала. Можно идти.» | NAVIGATION |

**Вытеснение обязательно.** Дослушивание предыдущей фразы стоит
полутора секунд, за которые человек делает два шага.

---

## Сценарий 9. Ориентиры (то, чего не было у предшественника)

Ориентиры не опасны и не попадают в поле риска, но незрячий
подтверждает по ним своё положение.

| Время | Реплика | Слой |
|---|---|---|
| 0:00 | «Идите прямо сто метров.» | routing |
| 0:25 | «Справа вход в здание.» | guidance (landmark) |
| 0:48 | «Слева светофор — это перекрёсток.» | guidance (landmark) |
| 1:10 | «Впереди лестница вниз, шесть ступеней, перила справа.» | fusion (danger) |

Ориентиры произносятся **только когда речь свободна** — они имеют
приоритет `INFO` и вытесняются всем остальным.

## Что из этого следует для реализации

| Требование | Модуль | Где проверяется |
|---|---|---|
| Действие раньше причины | `phrasing.py` | тест на порядок слов |
| Округление расстояний | `phrasing.py::round_distance` | есть |
| Метры только при малой σ | `scheduler.py` | `metric_sigma_threshold_m` |
| Бюджет 2.5 с | `scheduler.py` | `min_interval_s` |
| Вытеснение EMERGENCY | `scheduler.py` + `tts.py::interrupt` | |
| Смягчение при низком доверии | `phrasing.py` + `health` | |
| Фазы перехода | `fusion/policy.py::_crossing_phase` | |
| Подтверждение на нерегулируемом | `app/` + `fusion` | |
| Ориентиры с приоритетом INFO | `phrasing.py` | |
| Вибрация как дубль речи | `app/` | |

## Что нужно проверить на носителях языка

Все реплики выше — на русском. Казахские версии **не переводятся
дословно**: порядок слов другой (SOV), и калька звучит неестественно
там, где важна каждая доля секунды.

Требуется проверка носителем для:

* «Возьмите левее» — команда движения, должна быть короткой;
* «Стоп» — экстренная, одно слово;
* «Край тротуара» — тактильный ориентир;
* «Решение за вами» — формулировка ответственности;
* «Препятствий не вижу» — утверждение о системе, не о мире.

Последняя особенно важна: если в переводе она превратится
в «препятствий нет», смысл поменяется на противоположный и правило
безопасности будет нарушено.
