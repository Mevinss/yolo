# Диаграммы

Для статьи понадобятся (нумерация условная, уточним на этапе написания):

1. Архитектура системы по слоям
2. Поток данных за один кадр с таймингами
3. Поле риска: кадр -> полярная сетка (наглядная иллюстрация абстракции)
4. Слияние: три слагаемых стоимости и результирующий выбор угла
5. Кривая компромисса w_risk / w_route
6. Схема полевого стенда: iPhone + ноутбук
7. Карта маршрутов прогулок по Астане
8. Покрытие OSM тегами доступности по районам

Исходники держать в редактируемом виде, не только PNG:
рецензенты почти всегда просят правки к рисункам.
